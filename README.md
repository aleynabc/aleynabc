**[WarpMenu](https://github.com/aleynabc/WarpMenu)**
A C# and SMAPI-based mod for Stardew Valley that I built from scratch to add an in-game fast-travel menu. It runs entirely on SMAPI's own APIs without relying on Harmony patches, and supports 9 languages with a UI consistent with the game's native design. My goal was to learn, end to end, how a SMAPI mod is structured and how in-game UI is rendered.
`C#` `.NET 6` `SMAPI` `IClickableMenu`
